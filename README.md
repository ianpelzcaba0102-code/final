# TallerescExtracurriculares

Trabajo práctico inicial con ASP.NET Core MVC.

Autor: Ian Pelzmajer

Antes de ejecutar la aplicación por primera vez, confiar el certificado HTTPS de desarrollo:

```powershell
dotnet dev-certs https --trust
```

Luego, desde la carpeta del proyecto:

```powershell
dotnet run
```
